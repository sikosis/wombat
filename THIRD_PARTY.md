# Third-party components

Wombat includes the following dependencies as pinned Git submodules. They are
compiled directly into the executable and do not need to be installed on the
target Haiku system.

## Tree-sitter

- Version: 0.27.2
- Source: <https://github.com/tree-sitter/tree-sitter>
- Licence: MIT
- Purpose: incremental parsing runtime

## Tree-sitter Bash

- Version: 0.25.1
- Source: <https://github.com/tree-sitter/tree-sitter-bash>
- Licence: MIT
- Purpose: Bash and POSIX shell grammar
